# 시험 자료 (data/samples)

파이프라인 검증에 쓰는 공개 자료를 모아 두는 폴더입니다. 연구 1건당 폴더 하나에 아래 3종이 모두 있어야 합니다.

| 종류 | 위치 |
|---|---|
| 연구보고서 (hwpx · docx · pdf · hwp · tex 등 문서 형식 무관) | `report.<확장자>` (예: `report.pdf`) |
| 분석 코드 | `code/` |
| 연구에 사용된 데이터 | `data/` |

## 폴더 구조

```
data/samples/
  sample-01/               ← 원본 그대로
    report.<확장자>        ← hwpx, docx, pdf, hwp, tex 등
    code/
    data/
    SOURCE.md              ← 출처·라이선스 (필수)
  sample-01-modified/      ← 원본을 고친 경우에만. 같은 구조
    ...
    SOURCE.md              ← 무엇을 어떻게 바꿨는지 (필수)
```

새 자료는 [SOURCE_TEMPLATE.md](SOURCE_TEMPLATE.md)를 복사해 `SOURCE.md`로 채웁니다.

## 올리기 전 체크리스트

- [ ] 재배포가 허용된 자료인가 (공공누리 등 라이선스 확인, 상업 이용·변경 제한 여부 포함)
- [ ] 개인정보가 없는가 / 미공개 원고가 아닌가
- [ ] `SOURCE.md`를 작성했는가 (출처 URL, 라이선스, 받은 날짜)
- [ ] [docs/USED.md](../../docs/USED.md)의 「외부 데이터」 표에 한 줄 추가했는가
- [ ] 파일 하나가 100MB 미만인가 (초과 시 일부만 쓰거나 다운로드 링크·스크립트로 대체)
- [ ] 원본을 고쳤다면 `-modified` 폴더에 두고, 원본과 변경 내역을 `SOURCE.md`에 적었는가

원본과 수정본은 반드시 폴더를 나눕니다. 원본 폴더의 파일은 고치지 않습니다.

형식만 바꾼 변환본(예: docx·md·LaTeX를 hwpx로 변환)은 `sample-NN-hwpx`처럼 형식명을 붙인 폴더에 두고, 변환 도구·버전과 검증 결과를 `SOURCE.md`에 적습니다. 변환 도구가 처리하지 못하는 요소(인용·수식·표 캡션 등)를 변환 전에 글자로 풀어 쓴 경우에는 무엇을 어떻게 풀었는지도 적습니다.

## 폴더 구조의 예외

- **원래 구조 유지**: 원본이 이미 보고서·코드·데이터를 한 저장소에 함께 두고, 코드가 상대경로에 의존해 다시 실행할 수 있는 자료(예: `sample-12`, `sample-13`)는 위 구조로 나누지 않고 원래 구조를 그대로 둡니다. 보고서·코드·데이터의 위치는 `SOURCE.md`에 적습니다.
- **공개할 수 없는 부분을 뺀 경우**: 제3자 저작물(사진 등)처럼 원본을 그대로 올릴 수 없어 그 부분을 지운 자료(예: `sample-11-modified`)는 원본 폴더 없이 `-modified` 폴더만 둘 수 있습니다. 무엇을 왜 뺐는지와 검증 결과를 `SOURCE.md`에 적습니다.
- **실행하면 결과 파일이 덮어써지는 자료**는 `SOURCE.md`에 그 사실을 적고, 폴더를 복사한 뒤 실행합니다.
