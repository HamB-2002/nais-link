# 숫자내력 (LINK)

**보고서에 적힌 숫자를 코드 한 줄까지 되짚는 R&D 검증 에이전트**

2026 국가과학기술연구회 국가과학AI연구센터(NAIS) AI 해커톤 본선 · 팀 LINK · 참가분야: 성과 작성·연구행정

연구보고서와 논문에 적힌 숫자가 어느 데이터의 어느 분석에서 나왔는지 되짚어, 원본을 다시 돌린 결과와 대조하는 에이전트입니다. 원고에서 검증 대상 수치를 뽑아내고, 코드 저장소에서 그 값을 만든 줄을 찾아 격리 환경에서 재실행한 뒤, 값이 어긋나거나 출처를 찾지 못한 숫자를 위치와 원인 후보까지 붙여 표로 돌려줍니다. 되짚어지지 않은 값은 「출처 미확인」으로 갈라 사람이 채우고, 확정된 연결은 내력 파일로 남아 다음 개정판에서 다시 쓰입니다.

이 저장소에는 본선 대회 기간 중에 만든 결과물만 올라갑니다.

## 처리 흐름

문서 파서 → 수치 추출기 → 코드 인덱서 → 실행 샌드박스 → 대조 판정기 → 검증표 생성기

| 단계 | 하는 일 | 산출 |
|---|---|---|
| 수치 수집 | 원고(hwpx·docx·PDF·LaTeX)에서 수치를 위치와 함께 추출, 날짜·항목번호는 제외 | 수치 목록(값·단위·문맥·쪽) |
| 내력 추적 | 코드 저장소·데이터 폴더에서 그 값을 만든 스크립트와 줄을 찾음 | 수치 ↔ 파일·줄 연결 |
| 재실행 대조 | 격리 환경에서 재실행해 허용오차·반올림 규칙을 적용해 비교 | 일치 / 어긋남 / 재현 불가 |
| 되돌려주기 | 어긋난 값의 원인 후보와 고칠 문장 제시, 확정된 연결은 내력 파일로 보관 | 검증표 · 내력 파일 |

언어모델은 ① 검증 대상 수치 판별 ② 코드 후보 선택 ③ 차이 원인 분류 세 자리에만 쓰며, 값은 언제나 코드가 만듭니다.

## AI 윤리 및 신뢰성

- 전 과정을 연구자 환경 안에서 실행해 원고·데이터·코드를 외부로 보내지 않는 구성이 기본값입니다.
- 연결은 파일·줄 번호로만 제시하고, 근거를 못 찾으면 「출처 미확인」으로 남깁니다.
- 최종 판정은 연구자가 확정하며, 실행 로그에는 값이 아니라 위치만 기록합니다.
